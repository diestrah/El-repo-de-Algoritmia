# Imprimir una Lista en Orden Inverso de Forma Recursiva

## Enunciado

Dada una lista, implementa una función que la imprima en orden inverso, 
utilizando recursión, sin invertir la lista original.

## Ejemplo de ejecución

Insertando los valores `101, 103, 106, 108, 109, 112` al final de la lista (en ese orden), el programa debería imprimir:

```
101 103 106 108 109 112 
112 109 108 106 103 101 
```

La primera línea corresponde a la impresión iterativa de la lista original (ya implementada en la biblioteca), y la segunda a la impresión en orden inverso utilizando la función recursiva a implementar.

## Restricciones

- La solución debe implementarse **únicamente utilizando recursión**.
- No se debe **invertir la lista** original.
- El caso base de la recursión corresponde a alcanzar un nodo nulo (final de la lista).
