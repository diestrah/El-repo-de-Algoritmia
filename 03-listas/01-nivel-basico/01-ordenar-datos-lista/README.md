# Ordenar Lista (sin manipular nodos)

## Enunciado

Dada una lista con datos desordenados, implementa una función que la ordene 
de forma ascendente. La restricción principal es que **no se deben manipular 
los nodos de la lista**: solo se permite trabajar con el elemento (dato) 
contenido dentro de cada nodo.

## Ejemplo de ejecución

Insertando los valores `2, 86, 5, 6, 8, 12, 7` al inicio de la lista (en ese orden), 
el programa debería imprimir:

```
7 12 8 6 5 86 2 
2 5 6 7 8 12 86 
```

La primera línea corresponde a la lista antes de ordenar, y la segunda a la 
lista ya ordenada.

## Restricciones

- No se permite manipular los **nodos** de la lista (no se deben reordenar 
  punteros ni reestructurar el enlazado).
- Solo se puede modificar el **elemento** (dato) almacenado dentro de cada nodo.
