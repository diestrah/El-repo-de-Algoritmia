# 🟢 Nivel básico

Este nivel introduce las operaciones fundamentales sobre **listas simplemente enlazadas**. 🔗

> 🔗 Si pierdes un enlace, pierdes el resto de la lista.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- 🚶 recorrer una lista
- 🔍 buscar elementos
- ➕ insertar nodos
- ➖ eliminar nodos
- 👣 comprender el uso de `actual` y `anterior`
- 🔧 modificar enlaces sin perder nodos

## 👀 TIPS

Antes de programar, **dibuja la lista** con sus nodos y flechas, y marca dónde está `actual` y `anterior` en cada paso. Verás qué enlace debes cambiar primero para no perder nodos. ✍️
