# 🟢 Nivel básico

Este nivel introduce las operaciones fundamentales sobre listas
simplemente enlazadas.

## Objetivos

Al finalizar este nivel deberías poder:

- recorrer una lista
- buscar elementos
- insertar nodos
- eliminar nodos
- comprender el uso de `actual` y `anterior`
- modificar enlaces sin perder nodos
