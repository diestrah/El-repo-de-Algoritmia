# Ejercicios de Listas en C++

Colección de ejercicios progresivos para aprender y practicar 
listas ligadas en C++.

Los ejercicios están organizados por nivel de dificultad para avanzar
desde problemas simples hasta problemas con más complejos con recursión.


## Ruta de aprendizaje

### 🟢 Nivel básico

Este nivel introduce las operaciones fundamentales sobre listas simplemente enlazadas.
El objetivo es comprender el puntero siguiente de los nodos y cómo cambiar las referencias.

[Ver ejercicios →](./01-nivel-basico)


### 🔴 Nivel avanzado
Recursión aplicado a listas ligadas. 
Implementación de otras variantes de listas ligadas.

[Ver ejercicios →](./03-nivel-avanzado)

> El objetivo es dominar primero la recursión directa y comprender
> correctamente el funcionamiento de la pila de llamadas (stack).
