# Invertir una Lista de Forma Iterativa

## Enunciado

Dada una lista, implementa una función que invierta el orden de sus nodos, 
utilizando un enfoque iterativo (sin recursión).

## Ejemplo de ejecución

Para una lista con los valores `11, 22, 33, 44, 55`, el programa debería 
mostrar el resultado:

```
Lista original: 11 22 33 44 55 
Lista invertida: 55 44 33 22 11 
```

## Restricciones

- **No se deben crear nuevos nodos**: la inversión debe realizarse manipulando 
  únicamente las referencias (enlaces) de los nodos existentes.
- La solución debe implementarse de forma **iterativa** (no se permite recursión).
- La complejidad temporal del algoritmo debe ser **O(n)**.
