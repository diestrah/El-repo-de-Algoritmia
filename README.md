# 📚 El-repo-de-Algoritmia

Este repositorio reúne ejercicios e implementaciones de las principales estructuras de datos estudiadas en el curso. 🚀

## 💡 Recomendación de estudio

Mi recomendación para abordar este curso es **comprender primero la teoría**. Una vez asimilados los conceptos, practica con ejercicios sencillos e incrementa gradualmente la dificultad. <br>
Algoritmia no es un curso para mecanizar soluciones, sino para desarrollar la capacidad de analizar problemas, diseñar algoritmos y visualizar distintas formas de resolverlos.

## 📖 Temario

| # | Tema | ¿De qué trata? |
|---|------|----------------|
| 1 | [💪 Fuerza Bruta](01-fuerza-bruta) | Probar todas las posibilidades hasta encontrar la solución. |
| 2 | [🔁 Recursión](02-recursion) | Resolver un problema a partir de versiones más pequeñas de sí mismo. |
| 3 | [🔗 Listas](03-listas) | Estructura de nodos enlazados: recorrer, insertar, eliminar y reordenar. |
| 4 | [🥞 Pilas](04-pilas) | Estructura LIFO: el último en entrar es el primero en salir. |
| 5 | [🚶 Colas](05-cola) | Estructura FIFO: el primero en entrar es el primero en salir. |
| 6 | [✂️ Divide y Vencerás](06-divide-y-venceras) | Dividir el problema en subproblemas, resolverlos y combinar los resultados. |
| 7 | [🌳 Árbol Binario](07-arbol-binario) | Estructura jerárquica donde cada nodo tiene como máximo dos hijos. |
| 8 | [🔍 Árbol Binario de Búsqueda](08-arbol-binario-busqueda) | Árbol ordenado que permite buscar, insertar y eliminar de forma eficiente. |

## ⬇️ ¿Cómo clonar el repositorio?

Usa el cmd de Windows, o bash si estás en Linux o macOS, y ejecuta:

```bash
git clone https://github.com/diestrah/El-repo-de-Algoritmia.git
```

Para traer las actualizaciones del repositorio, ejecuta dentro de él:

```bash
git pull
```

## 🛠️ ¿Cómo abrir un proyecto?

Abre `CLion` y selecciona `Open Project`. El IDE reconocerá el `CMakeLists.txt` y generará los archivos necesarios para compilar y ejecutar el programa.
