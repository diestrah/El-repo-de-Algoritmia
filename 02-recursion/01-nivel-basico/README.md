# 🟢 Nivel básico

Este nivel introduce los conceptos fundamentales de **recursión** mediante ejercicios numéricos sencillos. 🔁

> 🔁 Caso base + llamada recursiva = problema resuelto.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- 🔍 comprender qué es una llamada recursiva
- 🛑 reconocer la importancia de definir el caso base
- 📉 reducir un problema a una versión más pequeña de sí mismo
- ↕️ comprender cómo avanzan y retornan las llamadas recursivas
- ⏮️ distinguir entre operaciones realizadas antes y después de la llamada recursiva
