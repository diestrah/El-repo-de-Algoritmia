# 🔁 Ejercicios de Recursión en C++

Colección de ejercicios progresivos para aprender y practicar **recursión** en C++. 🚀

Los ejercicios están organizados por nivel de dificultad, para avanzar desde problemas simples hasta problemas con estructuras más complejas, como arreglos y matrices.

> 🔁 Caso base + llamada recursiva = problema resuelto.

## 💡 Tips

Practica con 1-2 ejercicios básicos, luego con 1-2 intermedios y, después, intenta estudiar solo los avanzados. ✍️

## 🗺️ Ruta de aprendizaje

| # | Nivel | Qué practicas |
|---|-------|---------------|
| 1 | [🟢 Nivel básico](01-nivel-basico) | Recursión con números: caso base y llamada recursiva |
| 2 | [🟡 Nivel intermedio](02-nivel-intermedio) | Recursión sobre arreglos: trabajo con índices |
| 3 | [🔴 Nivel avanzado](03-nivel-avanzado) | Recursión sobre matrices: control de filas y columnas |

### 🟢 Nivel básico

Introduce los fundamentos de la recursión a través de problemas que trabajan con números: identificación del caso base y definición de la llamada recursiva.

➡️ [Ver ejercicios](01-nivel-basico)

### 🟡 Nivel intermedio

Aplicación de recursión sobre arreglos y trabajo con índices. El objetivo es comprender qué parámetros son necesarios para recorrer y procesar un arreglo mediante llamadas recursivas.

➡️ [Ver ejercicios](02-nivel-intermedio)

### 🔴 Nivel avanzado

Recursión aplicada a matrices, con manejo de dos dimensiones: filas y columnas. El objetivo es aprender a controlar múltiples índices y recorrer estructuras bidimensionales mediante recursión.

➡️ [Ver ejercicios](03-nivel-avanzado)

> [NOTA]
> En esta sección aún no se utilizan técnicas como backtracking, divide y vencerás o programación dinámica.
>
> El objetivo es dominar primero la recursión directa y comprender correctamente el funcionamiento de la pila de llamadas (*stack*).
