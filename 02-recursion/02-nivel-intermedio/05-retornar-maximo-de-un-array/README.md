# Máximo Valor de un Array Recursivo (con retorno)

## Enunciado

Implementa una función que retorne el máximo valor dentro de un arreglo de 
enteros, utilizando recursión.

## Ejemplo de ejecución

Para el array `{15, 23, 45, 7, 5, 16, 65, 84, 82, 15}`, el programa debería imprimir:
<br>
El maximo es: 84
<br>

## Restricciones

- La solución debe implementarse **únicamente utilizando recursión**.
- La función debe declararse con **dos parámetros** (el array y el índice/tamaño).
- La función debe **retornar un entero**.
- El caso base de la recursión corresponde a un índice igual a `0`.
