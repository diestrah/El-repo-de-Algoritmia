# 🟡 Nivel Intermedio

Este nivel refuerza los conceptos fundamentales de recursión mediante
su aplicación sobre arreglos.

Además, introduce la diferencia entre funciones recursivas que realizan
una acción y funciones recursivas que retornan un valor.

## Objetivos

Al finalizar este nivel deberías poder:

- identificar qué parámetros son necesarios para recorrer un arreglo mediante recursión
- definir correctamente el caso base al trabajar con arreglos
- utilizar índices para controlar el avance de las llamadas recursivas
- diferenciar entre funciones recursivas que realizan una acción y funciones que retornan un valor
