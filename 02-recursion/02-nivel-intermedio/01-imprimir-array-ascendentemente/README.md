# Impresión de Array por Índice Ascendente

## Enunciado

Implementa un programa que imprima los elementos de un array en orden 
ascendente según su índice, utilizando recursión.

## Ejemplo de ejecución

Para el array `{23, 17, 43, 12, 87, 43, 12}`, el programa debería imprimir:

23 17 43 12 87 43 12


## Restricciones

- La solución debe implementarse **únicamente utilizando recursión**.
- La función encargada de imprimir el array debe declararse con **dos parámetros** (el array y el índice/tamaño).
- El caso base de la recursión corresponde a un índice menor a `0`.
