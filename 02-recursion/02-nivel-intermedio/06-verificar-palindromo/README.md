# Palíndromo Recursivo

## Enunciado

Implementa una función que verifique si una cadena de caracteres es una palabra 
palíndroma, utilizando recursión. Una palabra palíndroma es aquella que se lee 
igual invirtiendo sus letras.

## Ejemplo de ejecución

Ingrese cadena: hola <br>
No es palindromo <br>
<br>
Ingrese cadena: 'reconocer' <br>
'reconocer' es palindromo <br>


## Restricciones

- La solución debe implementarse **únicamente utilizando recursión**.
- El caso base de la recursión corresponde a cuando el índice izquierdo supera al índice derecho.
