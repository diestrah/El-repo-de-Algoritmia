# Máximo Valor de un Array Recursivo

## Enunciado

Implementa una función que encuentre el máximo valor dentro de un arreglo de 
enteros, utilizando recursión. La función no debe retornar ningún valor 
(`void`); el resultado debe obtenerse a través de un parámetro pasado por 
referencia.

## Ejemplo de ejecución

Para el array `{15, 23, 45, 7, 5, 16, 65, 84, 82, 15}`, el programa debería imprimir:

El maximo es: 84


## Restricciones

- La solución debe implementarse **únicamente utilizando recursión**.
- La función debe declararse con **tres parámetros** (el array, el índice/tamaño, y una referencia donde se almacena el máximo).
- La función **no debe retornar ningún valor** (`void`).
- El caso base de la recursión corresponde a un índice menor a `0`.
