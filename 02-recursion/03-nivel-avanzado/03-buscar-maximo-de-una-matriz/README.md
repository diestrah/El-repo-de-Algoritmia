# Máximo Valor de una Matriz Recursiva

## Enunciado

Implementa una función que busque el mayor elemento dentro de una matriz, 
utilizando recursión. El resultado debe obtenerse a través de un parámetro 
pasado por referencia.

## Ejemplo de ejecución

Para la matriz:

```text
36 37 38 39
20 21 22 23
32 33 34 35
24 25 26 27
40 41 42 43
28 29 30 31
```

El programa debería imprimir:
<br>
El valor maximo es: 43


## Restricciones

- La solución debe implementarse **únicamente utilizando recursión** (no se permiten bucles para el recorrido de la matriz).
- El resultado debe obtenerse a través de un **parámetro pasado por referencia** (`max`), ya que la función es `void`.
- El caso base de la recursión corresponde a haber recorrido todas las filas de la matriz.
