# 🔴 Nivel Avanzado

Este nivel refuerza los conceptos fundamentales de recursión mediante
su aplicación sobre matrices.

## Objetivos

Al finalizar este nivel deberías poder:

- recorrer exitosamente una matriz
- definir correctamente los casos base al trabajar con matrices
- utilizar multiples índices para controlar el avance de las llamadas recursivas
- diferenciar entre funciones recursivas que realizan una acción y funciones que retornan un valor en una matriz
