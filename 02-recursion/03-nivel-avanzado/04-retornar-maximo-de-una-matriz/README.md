# Máximo Valor de una Matriz Recursiva (con retorno)

## Enunciado

Implementa una función que busque y retorne el mayor elemento dentro de una 
matriz, utilizando recursión.

## Ejemplo de ejecución

Para la matriz:

```text
36 37 38 39
20 21 22 23
32 33 34 35
24 25 26 27
40 41 42 43
28 29 30 31
```

El programa debería imprimir:
<br>
El valor maximo es: 43


## Restricciones

- La solución debe implementarse **únicamente utilizando recursión** (no se permiten bucles para el recorrido de la matriz).
- La función debe **retornar un entero** con el valor máximo encontrado.
- El caso base de la recursión corresponde a haber recorrido todas las filas de la matriz.
