# Ejercicios de Pilas en C++

Colección de ejercicios progresivos para aprender y practicar el uso de pilas en C++, utilizando una implementación propia.

El objetivo es comprender el principio **LIFO** (*Last In, First Out*: el último en entrar es el primero en salir) y aplicarlo en problemas de conversión, validación de expresiones y recursión.

## Estructura de los ejercicios

- `main.cpp`: contiene el programa de prueba y la solución del ejercicio.
- `BibliotecaPila`: biblioteca de apoyo para manipular las pilas.
- `README.md`: contiene el enunciado, ejemplos y restricciones.

## Ruta de aprendizaje

### 🟢 Operaciones básicas y aplicaciones

Primeros problemas para practicar la inserción, extracción y consulta de elementos, así como el manejo de pilas vacías.

| N.º | Ejercicio | Objetivo |
|---|---|---|
| 01 | [Convertir decimal a binario](./01-convertir-decimal-a-binario) | Utilizar el orden LIFO para mostrar los dígitos binarios en el orden correcto. |
| 02 | [Validar paréntesis](./02-validar-parentesis) | Comprobar el balance y anidamiento de paréntesis, corchetes y llaves. |

### 🟡 Recursión y manejo de varias pilas

Aplicación de la recursión para coordinar movimientos entre pilas respetando las reglas del problema.

| N.º | Ejercicio | Objetivo |
|---|---|---|
| 03 | [Torres de Hanói con pilas](./03-hanoi-con-pilas) | Representar las torres mediante pilas y trasladar los discos con el mínimo número de movimientos. |

### 🔴 Evaluación de expresiones y recursión sobre una pila

Problemas que requieren cuidar el orden de los operandos y comprender cómo se conservan los elementos durante las llamadas recursivas.

| N.º | Ejercicio | Objetivo |
|---|---|---|
| 04 | [Evaluar notación postfija](./04-evaluar-notacion-postfija) | Utilizar una pila para almacenar operandos y resultados parciales. |
| 05 | [Invertir pila sin estructuras auxiliares](./05-invertir-pila) | Invertir los elementos mediante recursión, sin utilizar una pila auxiliar. |
