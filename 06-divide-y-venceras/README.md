# ✂️ Divide y Vencerás

Resolver un problema **dividiéndolo en subproblemas más pequeños**, resolver cada uno y **combinar sus resultados**. 🧩

> ✂️ Dividir → Vencer → Combinar

## 🎯 Objetivos

Al finalizar estos ejercicios deberías poder:

- ✂️ dividir un problema en subproblemas independientes
- 🛑 definir el caso base de cada subproblema
- 🧩 combinar los resultados parciales en la solución final
- ⏱️ analizar la complejidad de una solución recursiva por mitades
