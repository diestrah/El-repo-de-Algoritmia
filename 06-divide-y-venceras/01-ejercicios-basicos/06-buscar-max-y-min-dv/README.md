# Mínimo y Máximo con Divide y Vencerás

## Enunciado

Dado un arreglo de números enteros, implementa una función recursiva en C++ que 
encuentre el valor mínimo y el valor máximo del arreglo, utilizando la técnica 
de **divide y vencerás**.

## Ejemplo de ejecución

Para el array `[8, 3, 10, 5, 2, 14, 1]`, el programa debería imprimir:

minimo: 1 <br>
maximo: 14


## Restricciones

- La solución debe implementarse **únicamente utilizando recursión**, siguiendo el enfoque de **divide y vencerás**.
- El resultado debe obtenerse mediante un (`struct`)** que contenga ambos valores (mínimo y máximo).
- El caso base de la recursión corresponde a cuando el índice inicial es igual al índice final del subarreglo.
- La complejidad temporal del algoritmo debe ser **O(n)**.
