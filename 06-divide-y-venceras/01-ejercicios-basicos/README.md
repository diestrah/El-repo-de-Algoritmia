# 🟢 Ejercicios básicos

Este nivel aplica la técnica de **divide y vencerás** sobre arreglos y cálculos numéricos sencillos. ✂️

> ✂️ Si puedes resolver cada mitad, puedes resolver el todo.

## 🎯 Objetivos

Al finalizar este nivel deberías poder:

- ✂️ dividir un arreglo o un problema numérico por la mitad
- 🛑 identificar el caso base (un solo elemento o exponente `0`)
- 🧩 combinar los resultados de las dos mitades
- 🔍 reconocer cuándo basta resolver una sola mitad (como en la búsqueda binaria)
