# 🔀 Mergesort

Tres ejercicios progresivos para entender cómo funciona **mergesort**: primero se aprende a **fusionar** dos arreglos ordenados, luego a **contar inversiones** mientras se fusiona y, al final, a aplicar **divide y vencerás** sobre un solo arreglo. ✂️

> 🔀 Dividir → Ordenar cada mitad → Fusionar

## 📚 Partes

| # | Parte | Dificultad | Tiempo |
|---|-------|------------|--------|
| A | [Insertar ordenadamente dos arrays (merge)](07a-insertar-ordenado-en-array) | 🟢 Básica | O(n + m) |
| B | [Contar inversiones de dos arrays (merge)](07b-contar-inversiones-de-dos-arrays) | 🟡 Intermedia | O(n + m) |
| C | [Contar inversiones completo (mergesort)](07c-contar-inversiones-completo-(mergesort)) | 🔴 Avanzada | O(n log n) |
