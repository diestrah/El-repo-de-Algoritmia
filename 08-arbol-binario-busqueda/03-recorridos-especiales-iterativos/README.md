# 🧭 Recorridos Especiales Iterativos

Recorridos que no siguen el patrón habitual y exigen **combinar ideas** de los recorridos anteriores. 🧩

## 🎯 Objetivos

Al finalizar esta sección deberías poder:

- 🧩 combinar pilas, colas y recorridos base para resolver un problema nuevo
- 🔲 identificar los nodos que forman el contorno de un árbol
- 📐 agrupar nodos que comparten una misma diagonal
