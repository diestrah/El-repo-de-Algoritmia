# 🥞 Recorridos DFS Iterativos

Recorren el árbol **en profundidad**: se baja por una rama hasta el final antes de pasar a la siguiente. Al ser iterativos, se apoyan en una **pila** que reemplaza a la pila de llamadas de la recursión. 🌿

## 🎯 Objetivos

Al finalizar esta sección deberías poder:

- 🥞 usar una pila para simular la recursión
- 🔀 distinguir cuándo se visita un nodo: antes, entre o después de sus hijos
- 🔁 convertir un recorrido recursivo en iterativo
