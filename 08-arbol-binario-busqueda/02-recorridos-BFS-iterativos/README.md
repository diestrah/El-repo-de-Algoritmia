# 🚶 Recorridos BFS Iterativos

Recorren el árbol **por niveles**: primero la raíz, luego sus hijos, luego los nietos, y así sucesivamente. Usan una **cola**. 🌊

## 🎯 Objetivos

Al finalizar esta sección deberías poder:

- 🚶 usar una cola para visitar los nodos nivel por nivel
- 📏 saber cuántos nodos tiene el nivel actual
- 🔀 variar el orden de salida (inverso o en zig-zag) sin cambiar el recorrido base
